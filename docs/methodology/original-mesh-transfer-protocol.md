# Original-mesh Transolver and geometry transfer

**Proposed for approval, 2026-11-18.** One seed on the AirfRANS full task, followed by a matched-flow comparison of 30 non-NACA UIUC shapes and 30 unseen NACA controls. The two questions are whether the field model improves on simple baselines on the official test set and how its errors and rankings change between these geometry groups at one operating point.

## 1. Qualify the pipeline

- Use the original processed AirfRANS VTU/VTP meshes and the pinned official case-name manifest. Stage and hash the source, ordered split lists, and converted files. Use the first 720 and last 80 of `full_train` for training and validation and retain all 200 `full_test` cases. The mapped remeshed card already matches the original manifest in order. Check the three-way disjointness of case IDs and canonical NACA shapes. Keep official test fields and labels out of preprocessing, fit, checkpoint selection and qualification. [Original AirfRANS data](https://airfrans.readthedocs.io/en/latest/notes/dataset.html), [staging commands](original-data-staging.md).
- Preserve original node coordinates and connectivity. Build the seven model channels from coordinates, inlet velocity, signed distance positive in the fluid, and wall normals pointing into the fluid. Obtain the wall mask by matching the wall patch to the internal mesh independently of target fields. Check the patch match, no-slip on the reference wall, near-zero wall distance, unit and outward wall normals against incident fluid cells, zero normals off-wall, and finite feature and target arrays. Fit pooled float64 channel means and population standard deviations on the 720 complete training meshes. Verify against an independent accumulator and attach the ordered fit-case list to the normaliser.
- On a full A100, execute the pinned authors' AirfRANS model and the local implementation in `eval()` with identical seed-0 reference weights and identical raw positions and normalised inputs. Require an explicit, complete parameter map for all parameters used in the upstream forward, and record upstream unused parameters and the regenerated grid. Check two distinct node subsets and one complete training mesh, in FP32 with TF32 disabled. All four output channels must pass `torch.testing.assert_close` with `rtol=1e-4`, `atol=1e-5`. Record actual maximum absolute and RMS differences per channel. The public source tree does not contain an AirfRANS checkpoint, so parity uses weights initialised by the authors' module and copied into ours. Use only the pinned model module with read-only fixtures in the isolated job. The check qualifies the forward implementation. [Parity command and pinned source](transolver-parity.md).
- Test the original-mesh prediction-to-force path on known fields before scoring predictions. Use the package's own `airfrans==0.1.5.1` integration. Pass the analytic uniform-pressure and linear-gradient invariants. For a frozen 12-case training audit, include the three existing force-audit cases and the first nine remaining official training-list cases with original and stored labels joined by case ID. Require the candidate integration of unchanged CFD fields to agree with direct `Simulation` integration on CL and CD, including pressure and viscous components, to absolute `1e-8`. Require direct total CL and CD to agree with the pinned stored coefficients to absolute `1e-5` each. Record all discrepancies. Use original-mesh integration as the reference for evaluation. [Prior three-case comparison](prototype-evaluation.md), [force implementation](https://airfrans.readthedocs.io/en/latest/_modules/airfrans/simulation.html).

## 2. Train and score once on the official test set

- Train the repository's default Transolver with seed 0, FP32, batch size one, 398 epochs, Adam and OneCycleLR at peak LR `1e-3`. Use the existing equal off-wall and wall normalised MSE loss. Visit each training case once per epoch in seeded shuffled order. For each update keep all wall nodes and draw off-wall nodes without replacement to reach 32,000 total nodes. Deliver the selected weights independently of the resumable state. The architecture and main hyperparameters follow the authors' AirfRANS configuration. The wall-retaining node sampling differs from the timing pilot's uniform draw and the authors' training sampler. [Upstream settings](https://github.com/thuml/Transolver/blob/75e0f67643806a81cd1d3f6adc88dd8c02416fe7/Airfoil-Design-AirfRANS/params.yaml), [pilot record](../../experiments/2026-11-17-original-a100-pilot/experiment.json).
- Validate at epochs 10, 20, …, 390 and 398, using a fixed per-case 32,000-node validation subset with all wall nodes and seeded off-wall sampling. Select the checkpoint with the lowest sum of the case-averaged, channel-averaged normalised wall and off-wall MSE. The earlier epoch wins an exact tie. The selection file records the eligible epochs, scores and checkpoint hash. Save atomically at every epoch boundary, including optimiser, scheduler and sampler/RNG states, next epoch and best checkpoint metadata. Verify interrupted versus uninterrupted continuation in a short test. Freeze the selected checkpoint and baselines before enabling the official test evaluation. No early stopping or extra seed. [Training and recovery commands](original-training.md).
- Run the frozen checkpoint once over the complete native mesh of each of the 200 official test cases. Use one full point set per forward, then integrate dimensional pressure and velocity on the original mesh. Score raw outputs for fields. Use exact no-slip on wall velocity for the primary coefficient integration and retain the raw-output coefficients as a diagnostic. Apply the same convention to official and matched CFD cases. Keep the retained test pass immutable and regenerate summaries from saved predictions and per-case metrics. [Official test evaluation command](original-test-evaluation.md).
- For the field baseline, predict the mean of the 720 training-case regional means in each channel, separately for wall and off-wall nodes. For the coefficient baseline, fit a separate quadratic ridge regression for each NACA family using the varying NACA parameters, Reynolds number and AoA. Standardise inputs within the training family, build degree-one and degree-two terms, drop constant terms, and fit CL and CD with an unpenalised intercept and a fixed ridge penalty of 1 in the sum-of-squares objective. Use original-mesh integrated training labels. Compare test metrics per channel and coefficient, with paired case bootstrap intervals for the mean error difference. Compare the sign and size of the improvements across quantities independently. [Baseline and freeze commands](original-training.md#fit-the-baselines-and-freeze-the-evaluation-inputs).

## 3. Reproduce the CFD and freeze the transfer cases

- Use the authors' case generator at `2dbf00c5ecbb8d6cef720db1e72c1fe40307eeab`, OpenFOAM v2112, steady incompressible `simpleFoam`, k-ω SST, a unit chord, and 298.15 K. Keep the pinned boundary conditions, reference pressure, block topology and mesh spacing settings. Feed both kinds of airfoil into the same geometry-to-blockMesh and VTK export pipeline, preserving the original closed-trailing-edge NACA geometry generator. Export the same cropped region and feature definitions as the original processed cases, and use the same force integration for both groups. Record runtime, mesher, conversion and solver versions and inputs. [Authors' case generator](https://github.com/Extrality/NACA_simulation/tree/2dbf00c5ecbb8d6cef720db1e72c1fe40307eeab), [AirfRANS meshing and boundary conditions](https://arxiv.org/html/2212.07564#A9).
- Freeze three reproduction cases from the 720 training IDs using the case-name operating conditions and family alone. In order, take the closest to `(Re=2.25e6, AoA=−4°, NACA 4)`, `(4.0e6, 5°, NACA 5)` and `(5.75e6, 12°, NACA 4)` using squared distance in `Re/1e6` and `AoA/5°`, with case ID as the tie-break. Reproduce the exact rounded inlet speed and angle of the selected cases. Use the generator's 20,000-iteration cap at |AoA| ≤ 10° and 40,000 otherwise. Every reproduction must pass `checkMesh`, produce finite fields, and meet all of the following against the released original mesh:

  | Quantity | Proposed gate per case |
  | --- | --- |
  | CL | absolute discrepancy ≤ max(0.02, 3% of absolute reference CL) |
  | CD | absolute discrepancy ≤ max(0.0005, 5% of absolute reference CD) |
  | Surface Cp | RMSE ≤ 0.05 on each of the upper and lower surfaces, interpolated at 99 evenly spaced points over x/c ∈ [0.01, 0.99]. Use the same far-field pressure reference and normalise kinematic pressure by 0.5 U∞². Save the overlaid profiles. |
  | Force convergence | difference of the last two successive 500-iteration means of monitored CL ≤ 0.002 and CD ≤ 0.00005. Apply this check to the matched cases too. |

- Fix the transfer operating point at Re = 4.0 × 10⁶ and AoA = +4°, with `U∞ = Re × ν / chord` using the pinned generator's viscosity. Use the same inlet vector, solver settings, output convention and mesh quality gates for all 60 runs. Freeze both groups and ranked reserves before surrogate inference. The official test set contributes only NACA geometry identifiers to this selection.
- **UIUC cohort.** Snapshot the UIUC coordinate index and files by SHA-256. Use published coordinates for conventional single-element sections. Screen filename and display name for NACA or NACA-derived profiles and exclude ambiguous identities in the recorded screening table before ranking. Parse Selig and Lednicer formats and require finite non-crossing upper and lower surfaces that are single-valued in chord fraction after unit-chord alignment. Accept 7–18% maximum thickness and at most 5% absolute camber. Permit a trailing-edge gap ≤ 0.002 chord and close it symmetrically with a cubic smoothstep over the last 2% chord. Use 199 interior cosine-spaced stations from a 201-point grid for the checks and duplicate comparison, with shape-preserving interpolation. Exclude a UIUC section within `0.001` chord pooled upper/lower RMS distance of any of the 1,000 original NACA sections. Sort eligible sections by SHA-256 of `airfrans-transfer-v1/<lowercase-filename>` and greedily discard near duplicates within the same RMS threshold against previously retained sections. The first 30 retained sections form the cohort and the remainder are ordered reserves. [UIUC coordinates and format notes](https://m-selig.ae.illinois.edu/ads/coord_database.html).
- **NACA controls.** Use only unique geometries in the 200 official test IDs, excluding all training, validation and reproduction shapes. Choose 15 four-digit and 15 five-digit controls by ascending SHA-256 of `airfrans-transfer-v1/<case-id>` within each family. Apply the same thickness and camber screen on the generated profiles. Use the next controls of each family as reserves.
- Publish the selection table, source checksums, exclusions, ranked reserves and final case IDs in the run artefacts. Replace a case only for a pre-specified geometry, mesh, nonfinite-output or force-convergence failure, taking the next eligible reserve from its group and, for controls, its family. A recoverable infrastructure failure can retry the identical case. Log every failed attempt and its allocation. Freeze 30 qualified cases per group before either group sees the model. If a group falls short within the cap, report the shortfall and incomplete transfer milestone. Keep CFD acceptance independent of model performance.

## 4. Measures and deliverables

- Report per-case and aggregate wall and off-wall normalised MSE and dimensional relative L2 for uₓ, uᵧ, p and νₜ. Use equal case weighting, with mean, P95 and P99 across cases. For transfer, also report area-weighted volume and arc-length-weighted wall MSE using lumped mesh weights, to check sensitivity to different node densities. Record wall-pressure and shear RMSE plus pressure and viscous CL/CD contributions. Use absolute CL/CD error as the primary magnitude measure. Report relative errors and defined counts alongside it, treating zero denominators as undefined. Report Spearman ρ independently for CL and CD.
- For transfer, report UIUC minus NACA-control mean per-case error and difference in Spearman ρ. Use 10,000 within-group shape resamples with replacement, NumPy PCG64 seed 0, and percentile 95% intervals. Use paired case resampling with the same settings for official-test model minus baseline differences. Call a mean-error improvement supported when its interval lies wholly below zero. Report undefined correlation draws and the number of defined replicates. These intervals describe variation across shapes under this protocol for one trained checkpoint. Report all discordant case pairs and rank displacements for CL and CD in each group, and count exact reference or predicted ties separately.
- Deliver the hashed selected checkpoint and normaliser privately, immutable case manifests, versioned CLI commands and Slurm configs, per-case dimensional predictions with mesh alignment, per-case metrics, and a short report covering pipeline qualification, official test and matched transfer. Every reported number or figure links to an `exp` run and its artefact. Register before execution, record failed and resumed allocations, and validate the tracker at close. Keep raw, derived, and checkpoint files out of Git.

## Approval and execution budget

- **GPU:** hard cap 24 full A100-hours including CUDA parity qualification, training, validation, recovery and both final evaluations. Reserve 30 minutes for qualification and 30 minutes for final inference. Use qualification to test full-mesh inference and measure actual loading and training throughput on a representative training subset before committing the full job. The existing 5.595 steps/s pilot implies 14.2 training-update hours for 286,560 updates and excludes full-dataset I/O and validation. The projected total must fit the cap. [A100 pilot, run `20261117T221946Z-2bdb`](../../experiments/2026-11-17-original-a100-pilot/experiment.json).
- **CFD:** hard cap 600 allocated CPU-core-hours including checks, failures, replacements and recovery. Use 16 cores per case. Request at most 50 minutes for each reproduction and 35 minutes per matched case (maximum 40 and 560 CPU-core-hours respectively for the initial 63 allocations). At 25 minutes each, 63 cases would use 420 CPU-core-hours. Use reproduction elapsed and iteration counts to assess feasibility for the in-range matched cases before submitting them. Only launch each wave if its requested allocation fits within the remaining cap. [Compute plan](../../PLAN.md#compute-budget-agree).
- Account from Slurm allocation rows, including jobs still consuming or reserving resources. Disable automatic requeue and resume explicitly from committed state inside the remaining budget. Keep outputs create-only per attempt. After approval, implement and register the agreed scope, then submit, monitor, recover and report within the envelope. Stop dependent work for a failed scientific gate requiring a protocol change, a cap that would be exceeded, or an access block. Weak predictive performance is a reportable result.
