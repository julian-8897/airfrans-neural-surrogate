# Prepare the matched geometry cohorts

Use the official AirfRANS split manifest, the saved UIUC coordinate index and the Standard `.dat` ZIP linked by the UIUC site. The command works from these snapshots and records their hashes. [UIUC coordinate archive and format notes](https://m-selig.ae.illinois.edu/ads/coord_database.html#archives).

```bash
uv run --locked --extra forces python -m airfoil_surrogate.cfd.cohorts \
  /path/to/Dataset/manifest.json /path/to/uiuc-index.html \
  /path/to/coord_seligFmt.zip --out "$EXP_OUT/cohorts"
```

`screening.json` records the decisions for the archive entries and for indexed geometry absent from the archive. Names from the index and coordinate header flag named NACA derivatives, named multi-element sections and ambiguous labels. The geometry parser handles Selig contours and Lednicer branches. It aligns the chord, applies the trailing-edge closure, and compares thickness, camber and pooled RMS distances on the proposed interior cosine grid. It uses the NACA profiles generated by the AirfRANS package for screening. The actual CFD setup uses the pinned generator.

`cohorts.json` gives the primary and reserve cases in each group with the shared operating conditions. For UIUC, it also gives hashes of the closed contours passed to the CFD runner. The NACA controls come from official test identifiers, with any identical geometries from the 800 training and validation IDs excluded. Ranks are deterministic within the UIUC group and within each NACA family. The selection command reads geometry and case IDs only.

Run the matched cases only after the protocol is approved and all three NACA reproductions pass. Freeze the final 30 qualified cases per group before inference. The primary and reserve ranks record the initial selection for that process.
